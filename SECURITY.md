# Security reports

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/leonhoulier/infomaniak-ai/security/advisories/new).
Do not publish API tokens, OAuth credentials, cookies, customer data or an active
exploit in an issue. Use synthetic examples and describe the affected version,
expected behavior and steps to reproduce.

If the private reporting form is unavailable, contact the maintainer through
[leonhoulier.com](https://leonhoulier.com) without including credentials.

Security fixes target the current release. The hosted service and self-hosted
runtime have separate deployment and upgrade steps; a merged fix is not proof
that every installation has been upgraded.
